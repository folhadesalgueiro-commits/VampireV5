## Reproduzir

Execute, no diretório do projeto:

```bash
npm ci
npm run import:documents
npm test
npm run build
npm run test:e2e
```

Node 24 é obrigatório; a versão usada é 24.19.0. Chromium pode ser configurado por `V5_BROWSER`. A importação depende das fontes privadas presentes ou de `V5_REFERENCE_DIR`. O ambiente atual mantém os documentos fora do repositório. A configuração de instalação e início foi consultada e permanece compatível. Estes testes não publicam uma nova configuração nem verificam uma nova restauração de snapshot.
